# oracle-arm-grabber

自动抢 **Oracle Cloud 东京区 Arm 免费服务器** 的小工具。

用 Playwright 接管你已登录的 Chrome，每 70 秒自动点一次「创建」，
直到抢到为止，抢到会弹窗 + 响铃 + 打开结果文件通知你。

---

## 为什么需要它

Oracle Always Free 的 Arm（Ampere A1）机器性价比极高，但东京区常年
**Out of host capacity（容量不足）**，手动点一天也未必抢得到。
这个脚本就是干这个的：挂着慢慢磨，等别人释放资源。

---

## 它能做什么

| 功能 | 说明 |
|---|---|
| 自动重试 | 每 70 秒点一次「创建」，失败就继续 |
| 抢到通知 | 弹独立窗口 + 响三声铃 + 记事本打开结果文件 |
| 结果文件 | 自动解析公网 IP，写好 SSH 用户名和完整连接命令 |
| 心跳状态 | 每轮刷新 `抢机状态.txt`，一眼看出脚本还活着没 |
| 卡住报警 | 连续 3 次找不到向导页 → 弹窗喊人，不会空转 |
| 看门狗 | `一键抢Arm服务器.bat` 会在脚本崩溃 10 秒后自动重开 |
| 优雅停止 | 建一个 `oci_retry.stop` 空文件，下一轮自动退出 |

---

## 使用前准备

1. **Windows + Node.js**
2. 装依赖：`npm i playwright-core`（纯 JS，不会拉 Chromium）
3. **Chrome 带调试端口启动并已登录 Oracle Cloud**：
   ```
   chrome.exe --remote-debugging-port=9222 --user-data-dir=<任意目录> --remote-allow-origins=*
   ```
4. 在控制台把**创建向导填好**（名称 / 规格 / 网络 / SSH 公钥），
   停在「复查」页，或者刚点过一次报「容量不足」。

   > 页面填好后**千万不要刷新**，一刷新向导就得重填。

---

## 怎么用

- 开始抢：双击 **`一键抢Arm服务器.bat`**（这个窗口要一直开着）
- 看状态：双击 **`看状态.bat`**
- 想停：直接关掉那个黑窗口

## 关于免费额度（很重要，别踩坑）

- **免费套餐账户的 A1.Flex 规格是锁死的**：
  OCPU / 内存那一栏是只读文本，只能用默认的 **1 核 6G**。
  想自定义必须先升级为 Pay As You Go（**要绑卡**）。
- **2026-06-15 起 Oracle 把免费 Arm 额度砍半了**：
  4 核 24G → 2 核 12G。4 核 24G 现在只有付费账户才保留。
- 免费资源**不扣钱、不需要卡**；卡只在「注册验证」和「升级付费」时需要。
- 认准「**符合始终免费条件**」这个绿色标签，别选没有标签的规格。

## 抢到之后

Oracle Linux 的 SSH 用户名是 **`opc`**（不是 ubuntu）。

```bash
ssh -i <你的私钥> opc@<公网IP>
```

---

## 工作原理（一句话）

`playwright-core` 通过 CDP 连上本机 Chrome → 在 Oracle 控制台的
**iframe** 里按坐标点「创建」按钮 → 读页面文本判断是「容量不足」还是成功。

> 坑点备忘：Oracle 控制台的 JET 组件用 `locator.click()` 会超时，
> 必须用「iframe 偏移 + 元素在 iframe 内的坐标」做真实鼠标点击。
