# oracle-arm-grabber

用浏览器自动化帮你抢 Oracle Cloud 的 **Ampere A1.Flex（Arm）** 免费服务器：
自动填创建向导 → 反复点「创建」→ 抢到弹窗 + 响铃 + 把 SSH 连接命令写到桌面。

不用 API key、不用装 OCI CLI，**只需要一个已经登录 Oracle 控制台的 Chrome**。

---

## 目录

| 文件 | 作用 |
|---|---|
| **`config.js`** | ★ 唯一需要你改的文件：抢哪个地区、多大规格、SSH 公钥 |
| **`oci_grab.js`** | 主程序（填向导 + 抢机） |
| **`一键抢Arm服务器.bat`** | 双击就开，带看门狗，崩了自动重启 |
| **`停止抢机.bat`** | 优雅停止（不放这个会留下半开连接） |
| **`看状态.bat`** | 看还在不在抢 |
| `announce.bat` / `announce_stuck.bat` | 抢到 / 卡住的弹窗提醒 |
| `填向导步骤.txt` | 想手动填表时照着抄 |
| `升级PAYG前后-必读.txt` | ★ 绑卡升级前先看这个，别莫名其妙被扣钱 |
| `oci_retry.js` | 旧版单地区抢机脚本（保留备用） |

## 快速开始

1. 用带调试端口的 Chrome 打开 Oracle 控制台并登录：
   ```
   "C:\Program Files\Google\Chrome\Application\chrome.exe" ^
     --remote-debugging-port=9222 ^
     --user-data-dir="%USERPROFILE%\WorkBuddy\2026-09-30-20-59-27\chrome-tmp" ^
     --remote-allow-origins=*
   ```
2. 双击 **`一键抢Arm服务器.bat`**。
3. 抢到会自动弹窗 + 响铃，桌面出现 `抢到了-Arm服务器.txt`（里面有公网 IP 和 SSH 命令）。

停止：双击 `停止抢机.bat`（脚本下一轮自己退出，别直接杀进程）。

## 三种运行模式

```bash
node oci_grab.js auto     # 全自动：填向导 + 反复抢（默认，推荐）
node oci_grab.js fill     # 只把向导填一遍并核对，填完就停
node oci_grab.js retry    # 只反复点「创建」（向导已经填好时用它）
```

## ★ 关于「其他地区能不能抢」—— 答案和代价

**技术上能**：把地区代号加进 `regions` 就行，脚本会自动切过去、重新填向导
（换地区必须用 `networkMode: 'new'`，因为 VCN 是按地区独立的，大阪没有东京的 VCN）。

**但钱上不划算**：Oracle 官方明文规定 ——
> Always Free 的 A1 **只能在主区域（home region）开**。
> 主区域开户时选定，**之后改不了**。

所以在东京以外抢到的机器 **不在免费额度内，会按量扣费**。
`regions` 默认只填了 `ap-tokyo-1`，就是为了防止你糊里糊涂花钱。

常用地区代号：`ap-tokyo-1`（东京）/ `ap-osaka-1`（大阪）/ `ap-seoul-1`（首尔）/
`ap-singapore-1`（新加坡）/ `us-phoenix-1`（凤凰城，Arm 资源最充足）。

## ★ 关于「绑卡（升级 PAYG）就能抢到吗」

**能，而且基本是必成。**
社区里大量案例：免费账户折腾一两周抢不到，升级后**第一次请求就成功**。
原因是免费账户和付费账户用的是不同的容量池，付费池基本不缺货。

但有两个前提，务必先看 `升级PAYG前后-必读.txt`：

1. **卡的类型**：Oracle 官方明文**不接受**虚拟卡、一次性卡、预付卡、带密码的借记卡。
   要的是 Visa / Mastercard 的**信用卡（credit）**且支持 **3D Secure**。
   同一张卡失败 2 次就停手，继续硬试会加重风控标记。
2. **顺序不能乱**：先停脚本 → 升级 → 设 1 美元预算告警 → 再改 config.js → 再抢 → 抢到立刻停。
   （不先停脚本的话，PAYG 一生效脚本会在几秒内抢到，超了额度就真扣钱。）

## ★ 免费额度到底是多少（2026-08 起，官方已更新）

| 项目 | 额度 |
|---|---|
| Arm Ampere A1 | **总共 2 OCPU + 12 GB**（旧说法 4核24G 已作废） |
| AMD Micro | 2 台 VM.Standard.E2.1.Micro（各 1/8 OCPU + 1 GB） |
| 块存储 | 200 GB 总计（引导卷最小 47 GB） |
| 出网流量 | 约 10 TB / 月 |

**免费账户下 OCPU / 内存是锁死的**（强制 1 核 6G），升级 PAYG 后才会解锁到 2 核 12G。
超过 2核12G 的部分就是真扣钱。

试用期结束时，如果 A1 实例总数超过 2 OCPU / 12 GB，
Oracle 会停用它们并在 30 天后删除（除非已升级付费账户）。

## 已知现实（别抱太大期望）

2026 年有实测记录：**东京区免费账户自动重试两周约 1500 次，成功 0 次**
（2核12G 约 800 次、1核6G 160+ 次全失败，深夜窗口也没用）。
同一账号升级 PAYG 后第一次请求就成功。

所以这个脚本的正确用法是：

- **免费账户**：当"零成本挂机"，抢到算赚，抢不到也不亏。
- **升级 PAYG 后**：几乎必成，几分钟内拿到机器。

## 常见问题

**Q：怎么知道还在不在抢？**
双击 `看状态.bat`，里面的"更新时间"跟现在差不到 5 分钟就是还在跑。

**Q：报"卡住了"弹窗怎么办？**
多半是浏览器被关了 / 掉线了 / 页面被刷新。重新打开控制台登录，再双击 `一键抢Arm服务器.bat`。
注意：Oracle 会话有时只是超时，等一会儿自己就好了，别急着重填。

**Q：抢到了但连不上？**
- Oracle Linux 的用户名是 **`opc`**（Ubuntu 才是 `ubuntu`），别写错。
- 复查页如果"公共 IPv4 地址 = 否"，说明子网没选对，抢到了也没有公网 IP。
  脚本会在日志里用 ★★★ 警告这一项。
- 安全列表默认几乎全封，需要去 VCN → 安全列表里放行端口。

**Q：一直显示"容量不足"正常吗？**
正常。东京 AD-1 常年缺货，脚本就是靠反复重试等释放。

## 安全提醒

- 仓库里**不包含**任何密钥、令牌、密码。私钥在你自己电脑上，公钥才可以公开。
- 抢到后**立刻停脚本**：免费额度只有 2核12G，脚本再抢一台就是纯扣费。
- 别在 `regions` 里乱加非主区域，除非你清楚那是要花钱的。
